# ClearBill demo video

Narrated 1080p walkthrough of the post-revamp UI (the `7447392` scannable
casebook build) for the Global AI Builder's Challenge submission on Devpost.
Everything below is produced locally and repeatably; no API keys, no
signed-in browser, no account of any kind.

## Files

| File | Role |
| --- | --- |
| `demo/narration.txt` | Voiceover source. One sentence per line, blank line between paragraphs. |
| `demo/steps.json` | The drive plan. `at` steps pin actions to narration marks (`"mark": "2.1"` = paragraph 2 sentence 1, resolved through `timing.json`). |
| `demo/timing.json` | Measured per-sentence start/duration from the synthesized audio. Regenerated by `synth`. |
| `demo/narration.wav` | Assembled voiceover (macOS `say`, voice Samantha, 175 wpm, 24 kHz mono). |
| `demo/captions.ass` | Lower-third captions burned into the video (white on a translucent dark box). |
| `demo/clearbill-demo.srt` | Companion captions file for upload forms. |
| `demo/clearbill-demo.mp4` | The finished video. |
| `demo/assets/tests_stdout.txt` | Real tail of `nice -n 15 npm test`, staged before every run and injected into the verification card. |
| `scripts/record-demo.mjs` | The whole pipeline: `stage`, `synth`, `probe`, `capture`, `check`, `all`. |
| `scripts/serve.mjs` | Zero-dependency static server; `capture` spawns it with `PORT=0` on an ephemeral port. |

## Reproduce

```bash
npm run demo          # stage + synth + capture end to end
npm run demo:stage    # re-verify the 1,290-test suite and restage the evidence
npm run demo:synth    # narration.txt -> narration.wav + timing.json + captions
npm run demo:probe    # dry run: every selector resolves, every click hit-tests
npm run demo:capture  # serve + headless Chrome drive -> demo/clearbill-demo.mp4
npm run demo:check    # ffprobe + volumedetect report
```

`capture` starts `scripts/serve.mjs` on an ephemeral port (`PORT=0`), drives
the real app in a throwaway headless Chrome (empty profile, remote debugging
port 0, real `Input.dispatchMouseEvent` clicks and a real slider drag, a
visible drawn cursor, downloads denied), resamples the screencast to a
constant 30 fps, muxes the narration and burns the captions in one ffmpeg
pass (`h264` `yuv420p` `color_range=tv` `+faststart`, `aac`). All temp files
live in `CLEARBILL_DEMO_TMP` (or a fresh `mkdtemp` dir) and are deleted on
exit. It aborts if the page ever navigates off the demo origin. The
`window.print` call is stubbed to a no-op only so headless Chrome cannot
block on a print dialog; the Print letter path still sets `data-print` and
the one-page letter is shown under emulated print media
(`Emulation.setEmulatedMedia`).

## Honesty note

The video is an honest capture of this repo running in a plain browser.
Every figure on screen is computed live by the app's own deterministic
engine over the fictional `demo-er` fixture: the `$2,453.00` bill, the
`$300.00` reported patient share, the `$120.00` to `$177.18` questioned
range, and the `$100.20` projection at 60% discount. The letter text and
its SHA-256 digest are generated by `src/ai-appeal-reasoning.js`
unchanged. The verification card shows verbatim tail lines of a real
`nice -n 15 npm test` run staged by `scripts/record-demo.mjs stage`
(`tests 1290`, `pass 1290`, `fail 0`); the `1,290` count is the real Node
suite. No live-network, insurer, hospital or patient outcome is claimed
anywhere: the app labels every case fictional, every flag is "a question
to ask", and the simulator callout reads "not a prediction or an offer".
